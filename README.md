# 📋 FastAPI Task Manager

A modern and asynchronous REST API built to manage tasks efficiently.

## 🚀 Key Features
- **CRUD Operations:** Create, read, update, and delete tasks.
- **Interactive Documentation:** Automatic API docs available at `/docs` (Swagger UI) and `/redoc`.
- **Fast & Async:** High performance powered by FastAPI and Python type hints.
- **Data Validation:** Robust request validation with Pydantic models.

## 🛠️ Tech Stack
- **Framework:** FastAPI
- **Language:** Python
- **Server:** Uvicorn
